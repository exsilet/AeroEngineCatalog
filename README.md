# AeroEngineCatalog

Консольный симулятор инженерных расчетов для авиационных двигателей.

## Проект Week1: Консольное приложение для каталогизации деталей

### Функциональность:
1. **Управление деталями двигателя**
   - Хранение информации о деталях (ID, название, материал, масса)
   - Поиск деталей по материалу
   - Добавление новых деталей

2. **Инженерные расчеты**
   - Расчет общего веса набора деталей (асинхронный)
   - Статистика по материалам (LINQ queries)

3. **Архитектура**
   - SOLID принципы
   - Разделение ответственностей
   - Интерфейсы для абстракции

### Технологии:
- .NET 8
- C# 12
- LINQ
- Async/Await
- Git / GitHub

### Как запустить:
1. Клонировать репозиторий
2. Открыть `Week1/AeroEngineCatalog.ConsoleApp.sln` в Visual Studio
3. Нажать F5 для запуска
